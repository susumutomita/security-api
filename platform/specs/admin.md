# 管理者機能（運営側）

> [SPEC.md](../SPEC.md) > 管理者機能

---

## ゲーム制御

| 機能 | 説明 |
|------|------|
| ゲーム開始 | ゲームタイマー開始、ヘルスチェック開始 |
| ゲーム停止 | ゲームタイマー停止、最終スコア確定 |
| スコア重み変更 | ダウンタイムペナルティの重みを変更（通常: -100pt ⇔ 高ペナルティ: -1,000pt） <!-- TODO: 確認中 --> |
| スコアボードブラックアウト ON/OFF | スコアボードの表示/非表示を切替。ブラックアウト中もゲーム・スコア変動は継続 |

## チーム管理

| 機能 | 説明 |
|------|------|
| チーム一括作成 | 複数チームを一括で登録 |
| ゲーム設定変更 | ポイント値、RTO、ヘルスチェック間隔等のパラメータ変更 |

## 妨害注入

| 機能 | 説明 |
|------|------|
| 手動妨害注入 | 任意のチームに任意の攻撃を手動で発動 |
