# ゲーム進行フロー

> [SPEC.md](../SPEC.md) > ゲーム進行

---

## 基本原則

- **「準備フェーズ→攻撃フェーズ」のような明確なフェーズ切替は存在しない**
- プレーヤーは **ゲーム開始時から全機能（攻撃・防御・同盟・サイドクエスト）にアクセス可能**
- 運営は裏側で **スコア重み（+100/-100のペナルティ倍率）** と **妨害注入タイミング** を制御する
- プレーヤーにはフェーズ切替が見えない

## 運営による制御

運営は以下を裏側で操作する：

| 操作 | 説明 |
|------|------|
| ゲーム開始 | タイマー開始、ヘルスチェック開始 |
| スコア重み変更 | ダウンタイムペナルティの重みを変更（-100pt → -1,000pt 等） <!-- TODO: 確認中 --> |
| 妨害注入 | 任意のチームに任意の攻撃を手動で注入（パスワードローテーション、S3サイト書き換え等） |
| スコアボードブラックアウト | 終了前の一定時間、スコアボードを非表示にする |
| ゲーム停止 | タイマー停止、最終スコア確定 |

## スコアボードブラックアウト

- ブラックアウト中はスコアボードが非表示になる
- ブラックアウト中もゲーム・スコア変動は継続する
- 最終結果はゲーム終了後に開示される

- **ブラックアウト開始タイミング**: ゲーム終了 **30分前** から自動的に開始される（確定）

## 想定される進行タイムライン

1. ゲーム開始 → ヘルスチェック開始（DOWN = -100pt/チェック）、全機能がプレーヤーに開放
2. チームはインフラ修復・脆弱性修正・攻撃・同盟・サイドクエストを並行して進める
3. 運営が任意のタイミングで妨害を手動注入（パスワードローテーション、S3改ざん等）
4. 妨害によりダウンしたチームは早急に復旧しないとマイナスが蓄積
5. 運営がスコア重みを変更する可能性あり（-100pt → -1,000pt） <!-- TODO: 確認中 -->
6. ブラックアウト開始（スコアボード非表示）
7. ゲーム終了 → 最終スコア確定・結果発表
